## 지도 구성

- **①** 기업 — 분야별 레이어를 켜고 끕니다(전자·제어·통신·센서 50, 하드웨어·소재 27 …).
- **②** 연구장비 — 원의 반지름이 `√장비수`. 전체 / 방산 관련만 전환, 기업 겹쳐 보기 가능.
- **③** 막대 차트(기업 분야별·방산 시험유형별)와 시군별 표.

## 주의

기업 위치는 **본사 주소** 기준이라 공장·연구소와 다를 수 있습니다.
방산 관련 장비 분류는 장비명·제조사·활용분야로 **추정**한 것이며 실제 납품 실적이 아닙니다.
